# 架构说明：华为云 Serverless MCP Servers

## 一、方案概述

本方案将 Model Context Protocol (MCP) 服务器部署于华为云，提供两种部署形态：

| 形态 | 适用场景 | 华为云服务 |
|------|---------|-----------|
| **无状态 Serverless** | 高并发、事件驱动、工具调用 | FunctionGraph + APIG |
| **有状态容器** | 长连接、会话保持、复杂状态 | CCE + ELB |

**MCP (Model Context Protocol)** 是一种 AI 工具调用协议，允许 AI Agent 通过标准化接口调用外部工具。

## 三、核心组件

### 3.1 APIG（API 网关）

| 配置项 | 说明 |
|--------|------|
| 协议 | HTTPS |
| 认证 | 令牌认证（Bearer Token） |
| 后端 | FunctionGraph HTTP 触发 |
| 限流 | 可配置 |

**端点设计**:
- `POST /mcp` - MCP 协议入口
- `GET /mcp` - SSE 长连接（可选）
- `DELETE /mcp` - 会话销毁

### 3.2 FunctionGraph（无状态）

| 配置项 | 说明 |
|--------|------|
| 运行时 | Node.js 18 / Python 3.11 |
| 内存 | 512 MB |
| 超时 | 10s（无状态）/ 300s（Agent） |
| 触发器 | APIG HTTP 触发 |
| 日志 | LTS |

**MCP Server 实现要点**:
- 使用 `@modelcontextprotocol/sdk` 库
- `StreamableHTTPServerTransport` 传输层
- 无状态模式：无 sessionIdGenerator
- 有状态模式：sessionIdGenerator = uuid

### 3.3 CCE（有状态）

| 配置项 | 说明 |
|--------|------|
| 集群类型 | 通用型CCE |
| 节点规格 | 2核4GB |
| Pod 数量 | 1-3（可配置） |
| 网络模式 | VPC-CNI |
| ELB | 独享型 ELB |

**会话保持**:
- 通过 cookie 实现
- 同一客户端请求路由到同一 Pod

### 3.4 认证方案（替代 Cognito）

| Cognito（参照服务） | 华为云替代 |
|-------------|-----------|
| User Pool | 自建用户表 + RDS |
| JWT 签发 | FunctionGraph 签发 HS256 JWT |
| JWKS 端点 | 自建 .well-known/jwks.json 端点 |
| 用户登录 | APIG 统一登录入口 |

## 四、网络设计

### 4.1 VPC 规划

```
VPC (10.0.0.0/16)
├── 子网1: 10.0.1.0/24 (可用区1)
│   └── CCE 节点 / FunctionGraph VPC 访问
├── 子网2: 10.0.2.0/24 (可用区2)
│   └── ELB / 公有端点
└── _nat_gateway: SNAT 出站
```

### 4.2 安全组

| 安全组 | 用途 | 入站规则 |
|--------|------|---------|
| apig-sg | APIG 入口 | 443 HTTPS |
| fgs-sg | FunctionGraph | APIG IP 白名单 |
| cce-sg | CCE Pod | ELB 健康检查 |
| elb-sg | ELB | 443 HTTPS |

## 五、数据流

### 5.1 MCP 协议调用流程

```
1. Client → APIG: POST /mcp (Bearer Token)
2. APIG → FunctionGraph: HTTP 触发
3. FunctionGraph: 解析 MCP JSON-RPC 请求
4. FunctionGraph: 调用 MCP Tools (业务逻辑)
5. FunctionGraph: 返回 MCP JSON-RPC 响应
6. APIG → Client: HTTPS 响应
```

### 5.2 工具调用示例

```json
// 请求 (MCP JSON-RPC 2.0)
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "book_hotel",
    "arguments": {"city": "深圳", "checkin": "2026-08-15"}
  }
}

// 响应
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [{"type": "text", "text": "酒店预订成功，订单号: HT20260815001"}]
  }
}
```

## 六、高可用设计

### 6.1 无状态方案

- APIG 多 AZ 部署
- FunctionGraph 自动弹性
- MCP 协议无状态特性天然支持水平扩展

### 6.2 有状态方案

- CCE 节点多 AZ 分布
- ELB 会话保持保证同一会话路由到同一 Pod
- OBS 作为会话持久化存储
